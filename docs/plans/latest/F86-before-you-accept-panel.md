# F86 — "Before you accept" effort panel

**Phase:** 3
**Area:** Frontend
**Status:** complete

## Goal

Add a collapsible "Before you accept" section to the Plan tab, positioned between the
metrics card (stat cards) and the "Needs attention" section. The panel tells the business
owner how much manual work remains before they can accept with confidence, framed in plain
language — not consultant billing units or developer hour rates.

All data is already available on `trustReport` and `planData`. No backend changes required.

## Acceptance Criteria

- [x] Panel renders between metrics card and Needs attention when `trustReport` exists and job is not accepted
- [x] Panel is hidden on accepted jobs
- [x] Headline counts (`10 of 15 steps automatic`, `5 require review`) are derived live from `trustReport`
- [x] Effort estimate (`~5 hours`) is computed from block counts × default rates
- [x] "How is this estimated?" disclosure is collapsed by default and expands inline
- [x] "Copy summary" copies a plain-text paragraph to clipboard and shows a toast confirmation
- [x] Risk warning renders when `reviewCount > 0` (aligned with final design — tied to steps, not risk label)
- [x] `make test` exits 0

## Effort rates (hardcoded defaults)

| Strategy | Hours per block |
|---|---|
| needs_review / translated_with_review | 1h |
| manual_todo / manual | 4h |
| failed_reconciliation | 2h |
| auto_verified / translated | 0h |
