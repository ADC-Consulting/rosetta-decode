# sas_finrep_sandbox

**Fictional client:** Apex Capital Management  
**Domain:** Month-end regulatory exposure reporting (Fixed Income & Credit)  
**Run date macro:** `RUN_DT = 20241231`

## What this project does

This SAS batch pipeline produces a month-end regulatory exposure report across Apex Capital's fixed-income and credit books. It:

1. Loads raw position data from a network share (`01_load_positions.sas`)
2. Loads instrument reference data and counterparty master (`02_load_reference.sas`)
3. Enriches positions with instrument/counterparty attributes, computes DV01 and EUR-equivalent market value (`03_enrich_positions.sas`)
4. Aggregates exposure by desk, asset class, and rating band (`04_aggregate_exposure.sas`)
5. Writes output datasets and exports CSVs for downstream regulatory submission (`05_produce_output.sas`)

## File map

| File | Purpose |
|---|---|
| `autoexec.sas` | Libname assignments, global %LET, OPTIONS |
| `macros/m_set_run_period.sas` | Derives period label, prior month-end, year from RUN_DT |
| `macros/m_log_step.sas` | Step logging utility (called by every pipeline script) |
| `macros/m_check_obs.sas` | Warns if a dataset is unexpectedly empty |
| `formats/finrep_formats.sas` | PROC FORMAT definitions for rating bands, desk labels, DV01 buckets |
| `sas/01_load_positions.sas` | INFILE/INPUT from raw CSV; date filter |
| `sas/02_load_reference.sas` | PROC IMPORT for instrument ref; staging counterparty |
| `sas/03_enrich_positions.sas` | PROC SQL multi-join; DV01 and currency normalisation |
| `sas/04_aggregate_exposure.sas` | DATA step RETAIN; PROC SUMMARY; PROC TRANSPOSE |
| `sas/05_produce_output.sas` | PROC EXPORT to CSV; PROC PRINT debug remnant |
| `sas/run_all.sas` | Batch entry point |

## Input data

| File | Location | Rows | Notes |
|---|---|---|---|
| `positions.csv` | `data/raw/` | ~180 | Trade positions across 3 desks |
| `instrument_ref.csv` | `data/raw/` | ~60 | Not all instruments have positions — intentional |
| `counterparty.csv` | `data/staging/` | ~40 | Pre-cleaned; some on watchlist |

## Golden output

| File | Corresponds to | Grain |
|---|---|---|
| `golden/pos_enriched_20241231.csv` | `work.pos_enriched` | One row per position |
| `golden/exposure_summary_20241231.csv` | `work.exposure_summary` | One row per desk × asset class × rating band |

Golden files are generated by `scripts/generate_finrep_golden.py` using the same business logic as the SAS pipeline but implemented independently in pandas.

## Known intentional issues

These are deliberate legacy smells, not bugs to fix:

- **Hardcoded date filter** in `01_load_positions.sas` (`>= '01DEC2024'd`) — should use `&RUN_DT.` but was never updated
- **LIBNAME ordering bug** — `autoexec.sas` defines `RAWLIB` with `&RUN_DT.` in the path, but `RUN_DT` is only set in `run_all.sas`, which runs after `autoexec.sas`
- **OPTIONS MPRINT** left uncommented in `run_all.sas`
- **Hardcoded FX rates** in `03_enrich_positions.sas` — EUR/USD/GBP rates are quarterly constants, not live
- **Orphaned PROC PRINT** in `05_produce_output.sas` (marked TODO)
- **Global scope leak** in `m_set_run_period.sas` — `PERIOD_LABEL` declared global because it is consumed by `05_produce_output.sas`
