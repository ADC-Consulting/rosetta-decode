# sas_kyc_aml_sandbox

**Fictional client:** Meridian Asset Partners  
**Domain:** Nightly KYC / AML screening and customer due diligence  
**Run date macro:** `AS_OF_DT = 20241231`

## What this project does

This SAS batch pipeline runs Meridian's nightly KYC/AML compliance process over its client book. It:

1. Ingests new/amended client onboarding records from the daily delta file (`01_ingest_clients.sas`)
2. Standardises identity attributes (name normalisation, SOUNDEX key, DOB validation) (`02_standardise_identity.sas`)
3. Screens clients against the consolidated sanctions/PEP/adverse-media watchlist using fuzzy name matching (`03_screen_watchlist.sas`)
4. Computes a composite Customer Risk Rating (CRR) from a weighted rules model (`04_score_risk.sas`)
5. Maintains a Type-2 history of the client master (`05_maintain_scd.sas`)
6. Builds an EDD work queue and produces a periodic review report (`06_build_edd_queue.sas`)

## File map

| File | Purpose |
|---|---|
| `autoexec.sas` | Libname assignments, global `%LET`, OPTIONS |
| `macros/m_set_review_window.sas` | Derives review-due cutoff dates per risk band from AS_OF_DT |
| `macros/m_log_step.sas` | Step logging utility (called by every pipeline script) |
| `macros/m_assert_nonempty.sas` | Aborts if a critical dataset is empty |
| `macros/m_screen_pass.sas` | Parameterised screening macro with `%DO` loop and hash object |
| `formats/kyc_formats.sas` | PROC FORMAT: country risk INVALUE, occupation cash-intensity, risk bands, channel risk |
| `sas/01_ingest_clients.sas` | INFILE/INPUT raw onboarding; PRXCHANGE name cleansing |
| `sas/02_standardise_identity.sas` | UPCASE/COMPRESS/PROPCASE, SOUNDEX blocking key, DOB validation |
| `sas/03_screen_watchlist.sas` | DECLARE HASH watchlist load; COMPGED/COMPLEV fuzzy matching |
| `sas/04_score_risk.sas` | IF/THEN/ELSE rules cascade; MERGE with risk_weights; band assignment |
| `sas/05_maintain_scd.sas` | SCD Type 2 client master maintenance |
| `sas/06_build_edd_queue.sas` | EDD filter; PROC REPORT + ODS RTF periodic review |
| `sas/run_all.sas` | Batch entry point |

## Known intentional issues

- **Hardcoded date filter** in `01_ingest_clients.sas` (`>= '01DEC2024'd`) — should use `&AS_OF_DT.`
- **LIBNAME ordering bug** — `autoexec.sas` defines `RAWLIB` with `&AS_OF_DT.` in the path but `AS_OF_DT` is set in `run_all.sas` (runs after autoexec)
- **COMPGED threshold drift** in `03_screen_watchlist.sas` — sanction threshold is 100 in one place and 120 in another (copy-paste drift, no comment)
- **OPTIONS MPRINT** left uncommented in `run_all.sas`
- **NOFMTERR** in `autoexec.sas` — masks unmatched format values silently
- **Global scope** in `m_set_review_window.sas` — `REVIEW_CUTOFF_HIGH/MED/LOW` declared global because consumed by `06_build_edd_queue.sas`
- **Orphaned PROC PRINT** in `06_build_edd_queue.sas` (marked TODO)
